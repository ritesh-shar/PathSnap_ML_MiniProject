# PathSnap — Route Reconstruction

A machine learning project focused on reconstructing road-network routes from noisy GPS trajectories using map-matching techniques.

## Tech Stack
- Python
- NumPy, Pandas, SciPy
- Scikit-learn, LightGBM
- Shapely, PyProj, NetworkX
- Optuna
- FastAPI
- Streamlit, Folium

## Project Structure
- `api/` — Backend API
- `data/` — Dataset
- `eda/` — Data exploration
- `features/` — Feature engineering
- `hmm/` — HMM and Viterbi
- `hpo/` — Hyperparameter optimisation
- `maps/` — Route visualisation
- `models/` — Machine learning models
- `results/` — Experiment results
- `ui/` — Frontend
